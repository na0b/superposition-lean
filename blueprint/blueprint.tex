\author{Qing Liu, Juan J. Manfredi, Xiaodan Zhou}

\begin{document}
\begin{abstract}
This document collects the natural-language statements and detailed proofs that accompany the Lean~4 formalization of the main results of
Q.~Liu, J.~J.~Manfredi and X.~Zhou, \emph{Superposition property in disjoint variables for the infinity Laplace equation}, RIMS K\^oky\^uroku Bessatsu B99 (2026), 19--34, arXiv:2508.17106.
Each subsection corresponds to the Lean declaration of the same name in the directory \texttt{Superposition/}; cross-references point to the results that a proof uses.
Items appear in dependency order.
\end{abstract}
