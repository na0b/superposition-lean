\begin{definition}[Elliptic operator, paper eq.~(ellip)]
Let $n\ge0$, let $\mathbb R^{n\times n}$ be the real $n\times n$ matrices and $\mathbb S^n\subseteq\mathbb R^{n\times n}$ the symmetric ones. For $X,Y\in\mathbb R^{n\times n}$ write $X\ge Y$ if $X-Y$ is positive semidefinite, i.e.\ $X-Y$ is symmetric and $\langle (X-Y)h,h\rangle\ge0$ for all $h\in\mathbb R^n$.

An operator $L:\mathbb R^n\times\mathbb R^{n\times n}\to\mathbb R$ is \emph{(degenerate) elliptic} if
\[
L(\xi,X)\le L(\xi,Y)\qquad\text{for all }\xi\in\mathbb R^n\text{ and all }X,Y\in\mathbb S^n\text{ with }X\ge Y .
\]
Only symmetric matrices enter this condition, so it is exactly the paper's ellipticity condition (ellip) for an operator $L(\xi,X)$ on $\mathbb R^n\times\mathbb S^n$ (the values of $L$ at non-symmetric matrices play no role).
\end{definition}
